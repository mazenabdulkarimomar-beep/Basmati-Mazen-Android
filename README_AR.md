# بصمتي – مازن | المعدات الدوارة – مصافي الشمال

مشروع تطبيق Android أصلي بلغة Java، وليس موقع ويب. يتطلب بناء APK عبر Android Studio أو خدمة بناء Android متوافقة.

## المناوبة
- تاريخ الأساس: الخميس 19 نوفمبر 2026.
- الخميس والجمعة: دوام كامل (البصمات 06:00، 16:00، 21:00).
- السبت: بصمة خروج 09:30.
- الأحد إلى الأربعاء: استراحة.
- تكرار كل 7 أيام.

## المزايا
- تقويم 14 يومًا قادمًا، محسوب تلقائيًا.
- أربعة منبّهات مستقلة، مع تشغيل وإيقاف وتعديل وقت البصمة والتقديم من 0 إلى 120 دقيقة.
- حفظ الإعدادات محليًا دون إنترنت.
- إعادة جدولة المنبه بعد إعادة تشغيل الهاتف أو تغيير الوقت/المنطقة الزمنية أو تحديث التطبيق.
- استخدام AlarmManager مع المنبه الدقيق عند منح الإذن، وإشعارات عالية الأولوية.

## بناء APK
1. افتح مجلد المشروع في Android Studio بإصدار يدعم Android Gradle Plugin 8.7.3 وJDK 17.
2. انتظر مزامنة Gradle (تحتاج إنترنت لتحميل الاعتماديات أول مرة).
3. اختر Build > Build APK(s).
4. يوجد الملف عادة في app/build/outputs/apk/debug/app-debug.apk.

## تنبيهات مهمة
- **هذا مشروع مصدر وليس ملف APK جاهزًا.** لم يُبنَ أو يُختبر على جهاز فعلي في بيئة الإنشاء.
- قد تمنع بعض أجهزة Android الإشعارات أو المنبّهات في الخلفية حسب إعدادات البطارية والأذونات.
- عند عدم منح إذن المنبّهات الدقيقة يستخدم التطبيق منبّهًا غير دقيق وقد يتأخر.
- المنبّه الحالي إشعار صوتي/اهتزازي عبر قناة النظام، وليس شاشة رنين كاملة أو إنذارًا مستمرًا.
- إذا اخترت تنبيهًا مبكرًا قبل منتصف الليل، قد يقع الإشعار في اليوم السابق للدوام.
